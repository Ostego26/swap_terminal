ASKED FOR BY THE OPERATOR 2026-10-01: "have it to where they can copy it directly with a little copy icon". Before this, `class="copyable"` existed in three places and was CSS ONLY -- styles.css:405 sets `user-select: all` so a click selects the whole string, and nothing in static/script.js touched the clipboard. The class promised an affordance the page did not have, which is rule 16's wrong comment wearing a CSS selector. WHY A MACRO AND NOT THREE BUTTONS. The deposit instruction on a tag chain is a PAIR -- account plus memo -- and the amount is a third string a customer retypes. Three hand-written buttons would be three chances for one to drift (rule 8), and the drift here is a button that copies the wrong field, which on a shared deposit account means a payment nobody can attribute. A data-copy="{{ value }}" would be a second copy of the one thing that must not differ, and an address that differs by one character is money gone. `user-select: all` is KEPT.
