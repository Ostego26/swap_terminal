Stop

Sends SIGTERM to each worker's recorded pid, waits {{ panel.grace }}, then SIGKILL — and then asks the operating system again whether each pid is gone. The answer you get back is that second question, not the exit code of the kill. It then scans /proc for a worker alive under a pid no file names, and reports it without signaling it.

Stopping moves no funds in either direction. What it costs while they are down is listed per worker below.
